## ✨ Overview

AeroMail is a next-generation desktop email application designed to simplify email communication while boosting productivity through AI-powered features. Inspired by modern email platforms like Gmail and Outlook, AeroMail provides a clean, responsive interface with intelligent tools for composing, organizing, and managing emails.

Whether you're handling business communication, personal emails, or team collaboration, AeroMail delivers a fast, secure, and user-friendly experience.

---

## 🚀 Features

- 📥 Receive emails using IMAP
- 📤 Send emails using SMTP
- 🤖 AI-powered email writing assistant
- 📝 Rich text and HTML email composer
- 📅 Schedule emails to send later
- 📎 File attachments
- ⭐ Star and mark important emails
- 🔍 Powerful email search
- 👥 Contact management
- 📊 Email analytics dashboard
- 📁 Drafts, Archive, Spam, and Trash folders
- 🌙 Light & Dark Mode
- 🔔 Desktop notifications
- 🔒 Secure authentication

## ⚙ Installation

Clone the repository

```bash
git clone https://github.com/hitman1c/AeroMail.git
```

Navigate into the project

```bash
cd AeroMail
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python main.py
```
